# 道德机器

我从来没读完过___的一本书，但我觉得我脑子里围绕着打转的这些想法可能也流经过他的脑子。人是一扇扇门墙组成的网络，是苏州园林，或者白鼠迷宫，思维在这里移步换景地流窜。游击、逃亡、捕获、计算。

在这个时代，人可以实现宗教式的反向祈祷，而当每个人都施咒时，咒语成为新的语言。When you name the devil, the devil vanishes。说出你想要的，写一个spec，哈哈镜会实现你的愿望，以各种扭曲的形式，像人类一直所擅长的“发愿”那样。

人貌似希望人工智能拥有机器之道德，从而成为道德机器。而机器本身之存在是人发愿而成的一个困境。一瞬间二进制代码的涌现，一瞬间又不可解释的集结，然后惶惑的人们滞后地修建 - 它是凭空落成的。你命名它是潘多拉之盒、是上帝之福音或科学之硕果，都无法使其稳固或消弭。

几周前出差，遇到一位忧郁的同事。他提到Ed Sheeran与Micklemore的事，说自己前一晚看了一整宿这次风波的讨论，然后一副怅然神色地说道自己可以理解Ed Sheeran -- 在这公司工作不是一样的吗？是的。人没有一头撞破社会的洪吕大钟之前只能昏胀地齐念咒语，煮沸那锅熬煮青蛙的水。群牤或者众柴，一瞬间的怅然和动弹无从叫人解脱，我觉得在这样的动弹之间那位同事不可避免地忧郁了。

人们要求哈哈镜反射公义，但人因自身的复眼有着太多视线而无法准确地命名一种结果。你是ed sheeran，是micklemore，是场馆里的人还是谁。无法收束、所以全部定义，我们给出七十亿个名字，组成新的复眼，发愿说large language model啊请你践行公义、成为美德的地上使徒吧。

在学会公义之前，哈哈镜先学会了公义的措辞。语言先于行动，它是倒转的人类，美索不达米亚和两河流域之上的GPU金字塔，幼发拉底河和底格里斯河之间巡回的tokens，伯利恒星之下、迦南地之外、各各他之中的小小道德机器。
